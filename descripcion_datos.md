
# Descripción de los datos

El archivo `fuente_datos_transporte.csv` contiene datos simulados de trayectos de buses del sistema de transporte masivo.

Campos:
- `bus_id`: identificador del bus.
- `hora_dia`: hora en la que se registra el punto de datos.
- `latitud` y `longitud`: ubicación GPS del bus.
- `velocidad_kmph`: velocidad estimada del bus.
- `dia_semana`: día de la semana en el que se registró el dato.

Este dataset fue generado con fines académicos para aplicar modelos de aprendizaje no supervisado.
