
# Pruebas realizadas

Se probó el modelo `KMeans` con diferentes cantidades de clusters (2, 3, 4, 5) y se analizó la visualización resultante.

Se seleccionó `n_clusters=4` por su balance entre simplicidad y diferenciación geográfica visible en la gráfica generada.

Se utilizó StandardScaler para normalizar los datos antes de aplicar el modelo, mejorando la calidad de los resultados.
